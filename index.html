가능성 분류 미션

문제 1 / 6

💬 생각을 더 넓혀 보기

“동전의 앞면이 나올 가능성”은 작다와 크다 중 어디에 속할까요?

앞면과 뒷면이 나올 가능성은 같으므로 정확히 절반입니다. 이렇게 가능성이 딱 중간인 상황은 네 가지 말만으로 나타내기 애매합니다. 그래서 가능성을 수로 표현하는 것이 필요합니다!
03

어떤 상자가 유리할까?

예상 시간 12분 · 빨간 공을 뽑으면 당첨! 공 하나를 무작위로 뽑습니다.

당신이라면 어떤 상자를 선택하겠나요?

A 상자

빨간 공 2개 / 전체 5개

B 상자

빨간 공 3개 / 전체 10개

상자를 선택해 보세요.

A 상자

2/5 = 0.4

B 상자

3/10 = 0.3
발견! 빨간 공의 개수만 보지 않고, 전체 공 중 빨간 공이 차지하는 비율을 비교해야 합니다. 따라서 A 상자가 더 유리해요.
왜 당첨 공이 3개인 B 상자가 꼭 유리한 것은 아닐까요?

0
불가능한 사건
0보다 크고 1/2보다 작음
가능성이 절반보다 작음
1/2보다 크고 1보다 작음
가능성이 절반보다 큼
1
확실한 사건
01/21

0 ≤ 확률 ≤ 1

정확히 1/2인 사건도 있어요. 확률은 0 이상 1 이하입니다.
